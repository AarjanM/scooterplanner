# ScooterPlanner

Free, open-source route planning and turn-by-turn navigation for Dutch mopeds
(bromfiets, snorfiets, speed pedelec). Google Maps routes mopeds like bicycles
and sends yellow-plate riders onto cycle paths they may not use. ScooterPlanner
routes by Dutch traffic law: carriageway and G12a bromfietspaden for a bromfiets,
cycle paths for a snorfiets, with municipal exceptions.

Status: **planning**. The way to a v1 spec is being charted as a
[wayfinder map](../../issues?q=label%3Awayfinder%3Amap) on this repo's issues.
